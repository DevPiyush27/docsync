# DocSync 🚀

A cross-platform document synchronization system connecting a web portal and a native Android application. Built for seamless file transfers and local organization.

> **Note:** This project is developed and maintained strictly for **personal use**. 

---

## 🛠️ Tech Stack
* **Android App:** Kotlin, Jetpack Compose (Gradle 8.10.2)
* **Web Portal:** HTML5, CSS3, JavaScript (`index.html`, `app.js`, `style.css`)
* **Backend / Storage:** Supabase

---

## 📱 Features
* **Cross-Platform Sync:** Connects a web client and a native Android application.
* **Modern UI:** Built with Jetpack Compose for a smooth mobile experience.
